# Объектно-ориентированное программирование в Python
## Решения заданий и практик из презентации

Проект содержит все задания слайдов 11, 19, 27, 31 и практики со слайдов 33–36.

### Структура
- `tasks/task_1_book.py` — класс `Book`, атрибуты и `info()`.
- `tasks/task_2_ebook.py` — наследование `Ebook` от `Book`, атрибут `format` и переопределение `info()`.
- `tasks/task_3_book_features.py` — `__str__`, `__eq__`, свойство `age` с сеттером и `classmethod from_string()`.
- `tasks/task_4_abstract_printable.py` — абстрактный класс `Printable` и реализация в `Book`.
- `practices/practice_1_employees.py` — наследование: `Employee`, `Manager`, `Developer`.
- `practices/practice_2_transport.py` — полиморфизм: родительский класс и три вида транспорта.
- `practices/practice_3_online_store.py` — модель интернет-магазина.
- `practices/practice_4_spaceship.py` — симулятор космического корабля.
- `tests/test_solutions.py` — автоматические проверки основных сценариев.

### Требования
Python 3.10 или новее. Сторонние библиотеки не нужны.

### Запуск
Запускайте нужный файл из корневой папки проекта, например:

```bash
python tasks/task_1_book.py
python practices/practice_3_online_store.py
```

Запустить все проверки:

```bash
python -m unittest discover -s tests -v
```

### Принятые решения
- Для года рождения/издания используется текущий календарный год.
- В интернет-магазине цена заказа рассчитывается так: сначала скидка, затем налог.
- Остатки товаров уменьшаются только при успешном оформлении заказа.
- В космическом симуляторе игровые события моделируются методами, чтобы результат можно было воспроизводимо проверить.
